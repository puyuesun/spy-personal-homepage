## 二、V1：个人主页基础版本

1. 顶部固定导航栏；
2. 首屏 Hero；
3. 关于我 About；
4. 技能 Skills；
5. 项目与经历 Projects & Experience；
6. 兴趣 Interests；
7. 联系我 Contact；
8. 页脚 Footer。

- 右侧提供“联系我”按钮。
- 页面滚动后导航栏加深并显示下边框。

#### 首屏 Hero

## 三、V2：视觉与交互升级版本

**版本定位**：V2 延续 V1 的主体内容结构，重点升级页面动态效果、卡片质感和主题能力。

### 1. 首屏动效升级

- 新增原生 Canvas 3D 漂浮粒子背景，桌面端约 520 个粒子。
- 粒子持续旋转、上浮，并通过近大远小营造景深感。
- 鼠标靠近时可缓慢推开粒子，移开后自然归位。
- 页面切到后台或开启减弱动效时自动暂停或降级。
- “联系我”按钮改为 Shimmer 扫光按钮，保留点击进入联系区的功能。

### 2. 全站动效与玻璃质感

- 首屏以外新增交互式网格背景。
- 指针所在格使用克莱因蓝高亮并带两层辉光。
- 指针离开后网格高亮约 1 秒淡出。
- 首屏不参与网格高亮，避免与粒子背景冲突。
- 半透明面板统一升级为 Glassmorphism 玻璃拟态。
- 玻璃效果统一使用模糊、饱和度、描边、内高光和柔和阴影等令牌。
- 深色磨砂面板和后续浅色玻璃面板共享统一变量。

### 3. 深浅主题切换

- 顶部导航栏右侧原“联系我”按钮改为深浅主题开关。
- 选中代表深色，未选中代表浅色。
- 开关控制全站 `<html data-theme="dark|light">`，不只改变按钮外观。
- 新增完整浅色主题，覆盖背景、导航、卡片、文字、标签、进度条、网格和联系方式控件。
- 浅色主题继续使用克莱因蓝，但改为浅蓝背景和深色文字。
- 首屏粒子会随主题切换不同蓝色配色，浅色模式整体透明度降为 `0.58`。
- 主题选择写入 `localStorage["spy-theme"]`，刷新后保持。
- 页面加载前提前恢复主题，避免刷新时闪烁错误主题。
- 开关支持键盘操作、`role="switch"` 和动态 `aria-checked`。

### 4. V2 相比 V1 的主要区别

| 功能 | V1 | V2 |
|---|---|---|
| 主题模式 | 固定深色 | 深色/浅色可切换并持久化 |
| 首屏背景 | 静态网格与光晕 | 3D 漂浮粒子 + 鼠标交互 |
| 首屏按钮 | 普通联系按钮 | Shimmer 扫光按钮 |
| 首屏以外背景 | 普通网格纹理 | 指针交互式网格 |
| 卡片材质 | 半透明卡片 | 全站玻璃拟态 |
| 页面内容 | 基础结构完整 | 内容结构基本不变 |
| 项目内容 | 占位 | 仍为占位 |

## 四、V3：反馈闭环与公开发布

**版本定位**：V3 在 V2 的视觉与交互基础上，不再重点改视觉，而是增加真实用户反馈能力，并把页面发布到互联网。

### 1. Feedback 悬浮按钮

- 右下角新增固定悬浮按钮。
- 桌面端约 100 × 100px，移动端约 84 × 84px。
- 环形 `FEEDBACK` 文字持续旋转。
- 鼠标悬停或键盘聚焦时，中心箭头切换为“意见反馈”。
- 点击后打开反馈弹窗。

### 2. 反馈弹窗与表单

- 使用原生 `<dialog>` 实现弹窗。
- 支持关闭按钮、Esc 键和点击遮罩关闭。
- 反馈内容为唯一必填字段，长度限制 1–1000 字。
- 实时显示字数计数。
- 提交中禁用按钮，避免重复提交。
- 成功后清空内容、显示提示并自动关闭。
- 失败后保留输入内容并显示错误信息。
- 深色和浅色主题分别适配弹窗、遮罩和输入区域。

### 3. Supabase 真实写入

- 使用原生 `fetch` 调用 Supabase REST API。
- 数据写入 `public.feedback` 表。
- 表字段只有 `id`、`message`、`created_at`。
- 前端只使用 Supabase anon public key。
- `service_role` 密钥禁止进入前端和公开仓库。

### 4. RLS 数据安全

- `feedback` 表启用 RLS。
- 匿名访问只允许 INSERT，不允许 SELECT。
- 匿名提交反馈返回成功，匿名读取反馈被数据库拒绝。
- 公开仓库不会暴露已有反馈内容。

### 5. GitHub Pages 发布

- 新增 `docs/` 发布目录。
- `docs/index.html` 作为公开入口。
- 仓库为 `puyuesun/spy-personal-homepage`。
- 发布路径为 `main / docs`。
- 公开地址：
  `https://puyuesun.github.io/spy-personal-homepage/`
- 项目从“只能本地预览”升级为“可以公开访问并收集反馈”。

### 6. V3 相比 V2 的主要区别

- 新增 Feedback 悬浮按钮和反馈弹窗；
- 新增 Supabase 真实写入；
- 新增 RLS 安全策略；
- 新增 GitHub Pages 公开发布；
- V2 的粒子、Shimmer、交互网格、玻璃拟态和主题切换全部保留；
- 头像、项目、奖项、GitHub、简历等内容仍然是占位。

## 六、迭代逻辑总结

四个版本对应四个阶段：

1. **V1：搭骨架**  
   先解决“页面能不能看、信息能不能找到、联系方式能不能用”。

2. **V2：做体验**  
   在不改变主体内容的前提下，加入粒子、网格、玻璃拟态、Shimmer 和深浅主题切换，让页面从静态展示变成可交互、可切换的科技感主页。

3. **V3：建闭环**  
   加入 Feedback 和 Supabase，把访客意见真正保存下来；同时通过 GitHub Pages 让主页公开可访问。

4. **V4：填内容与扩展能力**  
   把项目 01 从占位改成真实项目并上线，公开数字分身能力，让主页不仅能展示和收集反馈，还能与访客进行基于公开资料的 AI 对话。
