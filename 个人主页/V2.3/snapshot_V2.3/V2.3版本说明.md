## 1. 本版本做了什么

V2.3 当前实现是一件事：**把右上角原来的「联系我」按钮替换为可交互的主题开关**。

- 使用你指定的 Uiverse 组件：[jolly-chicken-91](https://uiverse.io/RiccardoRapelli/jolly-chicken-91)。
- 开关为天气/昼夜主题：未选中显示太阳与蓝天，选中显示月亮与星空。
- **未选中 = 浅色模式；选中 = 深色模式**。
- 开关控制 `<html data-theme="dark|light">`，不是只改按钮本身外观。
- 选择会写入 `localStorage` 的 `spy-theme`，刷新页面后保持。
- 首次访问默认深色，保持 V1 → V2.2 的原始视觉。
- 已补齐全站浅色主题：背景、导航、玻璃卡片、文字、标签、头像占位、进度槽、网格高亮与联系方式控件都会切换。
- 首屏 Canvas 粒子会随主题切换两组蓝色配色；浅色模式下整体透明度降为 `0.58`。
- 开关支持键盘聚焦，并使用 `role="switch"`、`aria-label` 和动态 `aria-checked`。

原来的导航栏「联系我」链接已移除；首屏 Hero 中的「联系我」Shimmer 按钮仍保留。

## 3. 主题切换机制

### 3.1 HTML

页面根节点：

```html
<html lang="zh-CN" data-theme="dark">
```

开关核心结构：

```html
<label class="theme-switch" for="themeSwitch">
  <input id="themeSwitch" type="checkbox" role="switch" checked />
  <span class="slider round">…</span>
</label>
```

### 3.2 无闪烁初始化

`<head>` 中先于样式表执行小段脚本：

```js
var savedTheme = localStorage.getItem("spy-theme");
document.documentElement.setAttribute(
  "data-theme",
  savedTheme === "light" ? "light" : "dark"
);
```

这样刷新时不会先闪现错误主题。

### 3.3 JavaScript

`script.V2.3.js` 第 0 节负责：

1. 读取当前 `data-theme`；
2. 监听开关的 `change`；
3. 更新 `data-theme`、`aria-checked` 和 `<meta name="theme-color">`；
4. 写入 `localStorage`；
5. 派发 `spy-theme-change` 事件；
6. 让首屏粒子模块切换对应配色。

## 4. 浅色主题设计

浅色模式继续使用克莱因蓝 `#002FA7`，但不保留大面积深色底。

### 4.1 主题令牌

`html[data-theme="light"]` 覆盖以下核心变量：

| 变量 | 浅色值 | 用途 |
|---|---|---|
| `--bg` | `#eef3fb` | 页面底色 |
| `--bg-2` | `#f8faff` | 浅色辅助底 |
| `--card` | `rgba(255,255,255,0.68)` | 玻璃卡片 |
| `--glass-border` | `rgba(0,47,167,0.14)` | 玻璃描边 |
| `--text` | `#101b34` | 主文字 |
| `--muted` | `#53627f` | 次文字 |
| `--faint` | `#7887a4` | 弱文字 |
| `--accent` | `#006edc` | 浅色模式强调色 |

### 4.2 重点适配

- 导航条改为浅色磨砂玻璃；
- 卡片改为白色半透明玻璃；
- Hero 姓名渐变改为深蓝克莱因蓝；
- 标签、头像占位、状态胶囊、复制按钮、兴趣图标改为浅色玻璃；
- 技能进度槽改为淡蓝凹槽；
- 交互网格线条与高亮降低对比度；
- 粒子改用 `#0b3a98 / #1d5fd6 / #3b74e8` 深层蓝色。
