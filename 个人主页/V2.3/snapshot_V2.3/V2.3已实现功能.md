## 一、本版本新增功能

### 1. 深色 / 浅色主题开关 ✅

- 位置：固定导航栏最右侧。
- 外观：Uiverse「Switch」by RiccardoRapelli，60 × 34 px。
- 未选中：蓝天、黄色太阳与云朵，对应浅色主题。
- 选中：黑色夜空、白色月亮、月斑与星星，对应深色主题。
- 支持点击整块开关与键盘聚焦。
- 使用 `role="switch"`、`aria-label` 与动态 `aria-checked`。
- 选中状态与 `<html data-theme>` 同步。

### 2. 全站浅色主题 ✅

浅色模式覆盖：

- 页面背景与顶部导航；
- 磨砂玻璃卡片、标签、状态胶囊、复制按钮；
- 首屏标题、正文、弱文字与强调色；
- 头像占位面板；
- 技能进度槽；
- 兴趣图标块；
- 交互网格线条和高亮；
- 页脚。

主色调仍为克莱因蓝 `#002FA7`。

### 3. 主题持久化 ✅

- `localStorage` 键：`spy-theme`。
- 可选值：`dark` / `light`。
- 默认：`dark`。
- 刷新页面后保持上次选择。
- `<head>` 中提前恢复主题，避免刷新闪烁。

### 4. 浏览器主题色联动 ✅

`<meta name="theme-color">` 随主题变化：

- 深色：`#05070f`
- 浅色：`#eef3fb`

### 5. 首屏粒子主题联动 ✅

- 深色粒子：`#2f6bff / #8ab4ff / #7ea6ff`
- 浅色粒子：`#0b3a98 / #1d5fd6 / #3b74e8`
- 浅色主题下 Canvas 整体透明度为 `0.58`。
- 切换主题时，已有粒子即时重新分配配色，无需刷新。

### 6. 减弱动效适配 ✅

`prefers-reduced-motion: reduce` 时：

- 云朵漂浮停止；
- 星星闪烁停止；
- 太阳/月亮过渡关闭；
- 原有 Shimmer、粒子与网格降级规则继续保留。

## 四、如何调整

### 4.1 调整主题开关

样式位于 `style.V2.3.css` 的 `.theme-switch` 小节。

常用参数：

| 想要的效果 | 调整位置 |
|---|---|
| 修改开关尺寸 | `.theme-switch` 的 `width` / `height` |
| 修改浅色天空 | `.theme-switch .slider` 的 `background-color` |
| 修改夜间背景 | `#themeSwitch:checked + .slider` |
| 修改太阳/月亮大小 | `.theme-switch .sun-moon` |
| 修改月亮位移 | checked 状态的 `translateX(26px)` |
| 修改云朵密度/位置 | `.cloud-light` / `.cloud-dark` 与云朵 ID 规则 |
| 修改星星位置 | `#theme-star-1` ~ `#theme-star-4` |

### 4.2 调整主题颜色

- 深色令牌：`:root`
- 浅色令牌：`html[data-theme="light"]`
- 玻璃模糊：`--glass-blur` / `--glass-blur-sm`
- 浅色网格：`html[data-theme="light"] .igrid rect`

### 4.3 调整粒子

见 `script.V2.3.js` 的 `PARTICLE_PALETTES` 与 `CONFIG`。

### 4.4 调整交互网格

见 `script.V2.3.js` 第 6 节顶部的 `CONFIG`。

### 4.5 调整原有 Shimmer

见 `style.V2.3.css` 的 `.btn-shimmer`。
