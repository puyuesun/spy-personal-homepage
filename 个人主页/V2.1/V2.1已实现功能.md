## 一、本版本新增功能

### 1. 首屏「漂浮 3D 粒子」动态背景 ✅

- 首屏 Hero 区背景为持续运动的 3D 粒子星场
- **持续旋转**：粒子绕中心轴匀速缓慢旋转
- **上浮漂移**：粒子以 0.75 px/帧 匀速向上浮动
- **近大远小**：基于透视投影的伪 3D，近处粒子更大更实、远处更小更淡
- **正确遮挡**：由远及近绘制，粒子前后层次关系正确
- **循环不枯竭**：粒子越界后从对侧重生并重新随机分布半径
- 效果来源：Magic UI `Floating 3D Particles`（原生 Canvas 等价移植，零依赖）

### 2. 粒子配色体系 ✅

- 克莱因蓝亮调 `#2f6bff`（62%）+ 浅蓝 `#8ab4ff`（24%）+ 浅蓝 `#7ea6ff`（14%）
- 整体统一在克莱因蓝的蓝色系内，不再出现青色点缀
- 颜色在 `script.V2.1.js` 的 `COLORS` 数组中集中配置，改一行即可换色

### 3. 鼠标指针推开粒子（首屏交互）✅

- 鼠标在首屏移动时，**指针附近的粒子被缓慢推开**，像拨开一层浮尘
- 指针移开后，粒子**缓慢合拢、回到原来的运动轨迹**，不留永久空缺
- 手感要点：
  - **缓慢、渐进**：散开与合拢都是平滑过渡（约 1 秒散开、约 3 秒完全归位），不是瞬间弹开
  - **没有弹跳**：采用「目标偏移 + 指数缓动」模型，公式中没有速度项，
    偏移只朝目标单调逼近，因此从原理上不会越过目标、不会来回震荡
  - **越近推得越远**：推开距离随距离平方衰减，影响半径边缘处几乎不动，过渡自然
  - **不会自激抖动**：距离按粒子的基准位置计算，不把粒子自身的偏移算进去
- 影响范围：半径 190 px，正中心最大推开 46 px（实测最大偏移约 35 px）
- 事件绑在 Hero 容器上，因此**鼠标移到标题、按钮上时同样能推开粒子**
- 参数集中在 `script.V2.1.js` 的 `CONFIG.interact`，改一行即可调
- 无障碍：系统开启「减少动态效果」时该交互自动停用并清空偏移

### 4. 首屏「联系我」按钮 —— Shimmer Button ✅

- 按钮启用 Magic UI `Shimmer Button` 效果：**边框一圈白光持续扫过**
- 具体表现：
  - **边框扫光**：一道白色光带沿按钮边缘流动，3 秒一轮、来回往复
  - **光带自旋**：光带本身以 6 秒一圈的速度旋转，扫光方向不断变化
  - **内部高光**：按钮下半部有内阴影反光，hover 时增强、按下时最亮
  - **交互**：hover 上浮 2px 并加深投影，按下回落 1px
- 保留原按钮的一切：文案「联系我 / Contact Me」、克莱因蓝主色、尺寸、跳转锚点 `#contact`
- 参数集中在 `style.V2.1.css` 的 `.btn-shimmer` 段（CSS 变量），改一行即可调
- 无障碍：系统开启「减少动态效果」时自动停用扫光动画

### 5. 边缘柔化过渡 ✅

- 首屏下沿与两侧对粒子做渐隐处理，粒子不会出现生硬截断
- 首屏与下方「关于我」区块之间过渡自然

### 6. 无障碍与性能保障 ✅

## 四、如何调整

### 4.1 调整粒子效果

打开 `script.V2.1.js`，文件顶部的 `CONFIG` 即为全部可调参数：

```js
var CONFIG = {
  quantity: 520,   // 粒子数量：想更稀疏改小，如 260
  size: 4.6,       // 粒子大小：想更细腻改小，如 3.5
  opacity: 0.42,   // 粒子亮度：想更明显改大，如 0.6
  drift: 0.75,     // 上浮速度：想更慢改小，如 0.4；设 0 则不上下浮动
  depth: 0.62,     // 3D 纵深：0 = 扁平，1 = 强烈近大远小
  interact: {      // 鼠标交互：指针推开粒子
    enabled: true, // 关掉就完全不响应鼠标
    radius: 190,   // 影响半径 px：想让鼠标影响范围更大改大，如 260
    displace: 46,  // 指针正中心最大推开距离 px：想推得更明显改大，如 70
    ease: 0.035    // 缓动系数：越小越慢越柔，如 0.02；越大越跟手，如 0.08
  }
};
```

### 4.2 调整鼠标推开粒子的手感

| 想要的效果 | 改哪个 |
|---|---|
| 散开得更明显 / 更含蓄 | `displace`（46 → 70 / 30） |
| 散开与归位更慢、更"飘" | `ease` 调小（0.035 → 0.02） |
| 更跟手、响应更利落 | `ease` 调大（0.035 → 0.08） |
| 影响范围更大 / 更集中 | `radius`（190 → 260 / 120） |
| 完全不想要这个交互 | `enabled: false` |

> 注意：`ease` 越小，指针移开后归位也越慢（指数缓动的必然结果）。
> 若想要"散开慢、归位快"，需要把代码里的单值 `ease` 拆成两个（散开 / 归位分开），可以再让我改。

### 4.3 调整 Shimmer 按钮

打开 `style.V2.1.css`，找到 `.btn-shimmer`，改顶部这几个 CSS 变量即可：

```css
.btn-shimmer {
  --shimmer-color: #ffffff;   /* 扫光颜色，改成 #8ab4ff 就是浅蓝扫光 */
  --spread: 90deg;            /* 光带张角，调小则光带更细长 */
  --speed: 3s;                /* 扫光周期，调小更快 */
  --cut: 0.1em;               /* 边缘光带宽度，调大扫光更明显 */
  --radius: 12px;             /* 圆角，改成 100px 即官方胶囊形 */
  --bg: linear-gradient(135deg, var(--klein) 0%, var(--klein-bright) 100%);
}
```

改完直接刷新页面即可看到效果，无需构建、无需重启服务。
