## 二、逐项功能说明

### F1 顶部固定导航栏

- 左侧品牌：中文名「孙璞月」+ 英文名「Spy」+ 发光装饰点

## 四、技术实现说明

- 单页结构 + 哈希锚点导航，锚点滚动由 CSS `scroll-behavior: smooth` 驱动
- 无任何第三方库、无构建步骤
- 语义化标签：`header` / `main` / `section` / `article` / `footer`
- 附加可访问性：`aria-label`、装饰元素 `aria-hidden`
- JavaScript 全部包裹在 IIFE 中，使用 `"use strict"`，不污染全局作用域
