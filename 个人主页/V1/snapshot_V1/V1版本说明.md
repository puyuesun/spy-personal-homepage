## 五、技术要点

- **纯静态页面**，无框架、无构建工具、无第三方依赖
- **不依赖外部网络资源**（字体使用系统字体栈），断网也能正常显示
- **响应式布局**：桌面三栏 / 平板两栏 / 手机单栏
- **可访问性基础**：语义化标签（`header` / `main` / `section` / `footer`）、`aria-label`、图片替代文案
- **哈希锚点平滑滚动**由 CSS `scroll-behavior` 实现
