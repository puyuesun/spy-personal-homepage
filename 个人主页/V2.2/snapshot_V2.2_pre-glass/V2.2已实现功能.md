## 一、本版本新增功能

### 1. 首屏以外区域的「交互式网格背景」✅

- 从「关于我」区块一直到**页脚**，整页背景铺一层 56px 的网格
- **指针停在哪一格，那一格就被填充成克莱因蓝**（`rgba(47, 107, 255, 0.2)`）
- **同一时刻只有一格**亮起（指针所在的那一格），不会连成一片
- 网格默认只有细描边、无填充，安静不抢内容
- **高亮的那一格会发光**：内层 6px 亮晕紧贴格子、外层 16px 柔光向外扩散，
  光会溢出格子边界照到周围；高亮时描边同时提亮（`rgba(110, 160, 245, 0.55)`），轮廓清晰不糊
- 发光不会把格子冲成灰蓝：实测高亮时格子内部平均色 RGB(25, 50, 100)，是饱和的深蓝
- **亮度经过两轮调整**：初版偏含蓄 → 增强（内部亮度 98.70）→ **按反馈压暗到 58.50**，
  发光保留（格子外圈仍比未高亮时亮 4.42）。详见 `V2.2版本说明.md` 第 4.6 节
- 效果来源：Magic UI `Interactive Grid Pattern`（原生 SVG + JS 等价移植，零依赖；
  发光是在官方基础上按需求追加的增强）

### 2. 「快进慢出」的高亮过渡 ✅

- **进入**：指针落到某格上，该格 **0.1 秒**快速点亮（官方 `duration-100`）
- **离开**：指针移开后，该格 **1 秒**缓慢淡出（官方 `duration-1000`）
- 淡出是**渐变过程**而非瞬间消失：实测填充 alpha 从 `0.2` 经 `0.16` 平滑衰减到 `0`
- **填充、描边、发光三者一起淡出**（过渡属性为 `fill, stroke, filter`），不会出现「光还在但格子没了」
- 与官方组件的观感完全一致

### 3. 自动适配容器尺寸 ✅

- 方格数量不是写死的，而是按容器实际宽高计算：`列数 = ceil(宽 / 56)`、`行数 = ceil(高 / 56)`
- 实测 1440×1000 视口下为 **26 列 × 57 行 = 1482 格**
- 窗口尺寸变化时自动重建网格
- 首屏高度变化时（`ResizeObserver` 监听 `.hero`）自动更新 `--hero-h` 并重建

### 4. 与首屏网格严丝合缝 ✅

- 首屏静态网格与内容区交互网格的方格**都是 56px**，视觉上是同一张网格
- 内容区网格的纵向起点做了偏移补偿（`offsetY = 首屏高度 % 56`，实测 11px），
  因此两套网格的线条在首屏交界处**完全对齐**，不会错开半格

### 5. 滚动后的高亮校正 ✅

- 页面滚动后，网格层相对视口的位置变了
- 若指针不动，脚本会用**最近一次指针位置重新计算**格子，避免高亮停在旧格子上
- 采用「重新定位」而非「直接清空」，避免滚动事件晚于鼠标事件时误清刚点亮的那一格

### 6. 无障碍与性能保障 ✅

| 能力 | 说明 |
|---|---|
| 减弱动效适配 | 系统开启「减少动态效果」时取消填充过渡，高亮改为瞬时切换（保留反馈、去掉动效） |
| 纯装饰层 | 网格层 `aria-hidden="true"`，不进入无障碍树 |
| 不挡操作 | `pointer-events: none`，不阻挡卡片按钮点击与文字选择 |
| 不触发重排 | 网格层位置测量结果被缓存，指针移动时不读取布局、不强制重排 |
| 只动两个节点 | 切换高亮时仅修改上一格与新格两个 `<rect>` 的类名 |

### 7. 页面小改进 ✅

- 新增 CSS 变量 `--hero-h`（首屏实测高度，由脚本写入），供两个背景层统一定位
- 页面标题、页脚版本标识（两处）统一更新为 V2.2

## 四、如何调整

### 4.1 调整交互网格

打开 `script.V2.2.js`，找到第 6 节顶部的 `CONFIG`：

```js
var CONFIG = {
  cell: 56,        // 方格边长 px：想更密改小（如 40），想更疏改大（如 80）
  enabled: true    // 设 false 则网格照常显示，但不再跟随指针高亮
};
```

打开 `style.V2.2.css`，找到 `.igrid rect` 与 `.igrid rect.is-hover`：

```css
.igrid rect {
  stroke: rgba(47, 107, 255, 0.05);  /* 网格线颜色 / 浓淡：改 alpha 即可，调大更清晰 */
  /* 离开时的淡出时长与属性（官方 1000ms）；发光也要一起淡出，所以列上 filter */
  transition: fill 1s ease-in-out, stroke 1s ease-in-out, filter 1s ease-in-out;
}

.igrid rect.is-hover {
  fill: rgba(47, 107, 255, 0.2);     /* 高亮填充色：改 alpha 调浓淡（当前值） */
  stroke: rgba(110, 160, 245, 0.55); /* 高亮时的描边 */
  /* 两层辉光：第 1 个 6px 是贴边的亮晕，第 2 个 16px 是向外扩散的柔光 */
  filter: drop-shadow(0 0 6px rgba(110, 165, 255, 0.55))
          drop-shadow(0 0 16px rgba(47, 107, 255, 0.32));
  transition-duration: 0.1s;         /* 进入时的点亮时长（官方 100ms） */
}
```

| 想要的效果 | 改哪个 |
|---|---|
| 网格更密 / 更疏 | `CONFIG.cell`（56 → 40 / 80），线条粗细会自动跟随对齐 |
| 网格线更深 / 更淡 | `.igrid rect` 的 `stroke` alpha（0.05 → 0.09 / 0.03） |
| 高亮更亮 / 更暗 | `.igrid rect.is-hover` 的 `fill` alpha（当前 `0.2`，调大更亮） |
| **发光更强 / 更弱** | `.igrid rect.is-hover` 里两个 `drop-shadow` 的 **alpha**（当前 `0.55` / `0.32`，调小即变含蓄） |
| **发光范围更大 / 更小** | 两个 `drop-shadow` 的**模糊半径**（当前 `6px` / `16px`） |
| 完全不想要发光 | 删掉 `.igrid rect.is-hover` 的 `filter` 两行即可（描边提亮会保留） |
| 淡出更快 / 更慢 | `.igrid rect` 的 `transition: … 1s`（改成 `0.5s` / `2s`） |
| 填充更快 / 更慢 | `.igrid rect.is-hover` 的 `transition-duration`（0.1s → 0.2s） |
| 完全不想要指针高亮 | `CONFIG.enabled = false`（网格保留） |

> 经验值参考：内部亮度 `36` ≈ 很含蓄、`58` ≈ 当前、`99` ≈ 明显偏亮刺眼；
> 发光强度的表现可以看「格子外圈比未高亮时亮多少」（当前 +4.4，增强版为 +13.4）。

### 4.2 调整首屏粒子（V2.1 参数，本版本未变）

打开 `script.V2.2.js`，文件顶部的 `CONFIG`：

```js
var CONFIG = {
  quantity: 520,   // 粒子数量
  size: 4.6,       // 粒子大小
  opacity: 0.42,   // 粒子亮度
  drift: 0.75,     // 上浮速度
  depth: 0.62,     // 3D 纵深
  interact: {      // 鼠标推开粒子
    enabled: true,
    radius: 190,   // 影响半径 px
    displace: 46,  // 最大推开距离 px
    ease: 0.035    // 缓动系数：越小越慢越柔
  }
};
```

### 4.3 调整 Shimmer 按钮（V2.1 参数，本版本未变）

打开 `style.V2.2.css`，找到 `.btn-shimmer`，改顶部 CSS 变量：

```css
.btn-shimmer {
  --shimmer-color: #ffffff;   /* 扫光颜色 */
  --spread: 90deg;            /* 光带张角 */
  --speed: 3s;                /* 扫光周期 */
  --cut: 0.1em;               /* 边缘光带宽度 */
  --radius: 12px;             /* 圆角，改成 100px 即官方胶囊形 */
}
```

改完直接刷新页面即可看到效果，无需构建、无需重启服务。
