# EXT1 已实现功能清单 — 小月 AI 数字分身

> 版本：EXT1  
> 日期：2026-09-18  
> 基线：V3  
> 角色名：小月 / Xiaoyue

## 一、已完成

### 1. 右下角数字分身入口

- 数字分身按钮位于 Feedback 上方，形成竖向入口栈。
- 桌面按钮 100 × 100 px，移动端 84 × 84 px。
- 按钮包含旋转轨道、头像字符和在线呼吸点。
- 打开聊天窗后支持关闭按钮、Esc、点击遮罩关闭。

### 2. 原创轻量 2D 角色

- 角色为页面内原创 SVG，不依赖外部图片、真人照片或模型素材。
- 视觉方向：亲和科技女生、克莱因蓝与青色科技服装。
- 支持待机呼吸、眨眼、思考、说话和离线状态。
- `prefers-reduced-motion` 下关闭循环动画。

### 3. 数字分身聊天窗

- 桌面宽约 380 px、高约 600 px；移动端接近全屏并保留安全边距。
- 深色 / 浅色主题自动联动。
- 支持建议问题、会话内上下文、自动滚动和输入计数。
- 支持 Enter 发送、Shift+Enter 换行。
- 回答使用 SSE 流式渲染，角色在回答期间切换为说话状态。
- 页面刷新后聊天记录清空，不使用 localStorage 持久化正文。

### 4. 安全与边界

- 持续显示“AI 数字分身、不是本人实时回复”的身份提示。
- 使用第一人称介绍，但不能代表本人承诺、签约或提供私人信息。
- 项目、简历、奖项缺失时明确回答“暂未公开”。
- 拒绝代做作业、考试和通用开发任务，可将适度闲聊引导回公开资料。
- 中文和英文回答自动跟随访客语言。

### 5. 知识库与资料速答

- `knowledge.EXT1.json` 覆盖身份、学校、专业、年级、技能、兴趣、学习方向、个人主页项目、联系方式和 FAQ。
- 无 Edge Function 或服务异常时，自动使用本地 FAQ 速答。
- 已通过 30 条中英文问题矩阵验证。

### 6. Supabase Edge Function

- `POST /functions/v1/twin-chat`。
- 使用 DeepSeek `deepseek-chat` 流式接口。
- 系统提示区分事实层与风格层，事实优先。
- 请求包含会话内历史，但不把聊天正文写入数据库。
- 支持 `TWIN_ENABLED` 紧急开关和 `TWIN_MOCK` 测试模式。

### 7. 防滥用与费用保护

- 首次会话使用 Cloudflare Turnstile。
- 单会话 8 条、单 IP 每日 20 条、全站每日 120 条。
- Supabase 只保存哈希会话、哈希 IP、次数、token 和估算费用。
- 月度预算默认 15 元；约 12 元告警，达到上限后停止模型调用并降级 FAQ。
- 日限额数据超过 30 天自动清理。
- CORS 默认仅允许 GitHub Pages、localhost 与 127.0.0.1。

### 8. 发布与文档

- 已同步到 `docs/` GitHub Pages 镜像。
- 已生成深色整页、浅色整页、深色聊天、浅色聊天和 390 px 移动端截图。
- 已提供 Supabase SQL、Edge Function 源码、部署说明和版本说明。
- 未创建 `snapshot_EXT1/`，因为用户未明确要求快照。
