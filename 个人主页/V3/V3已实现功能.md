## 一、本版本新增功能

### 1. 右下角 Feedback 悬浮按钮 ✅

- 固定在右下角，始终悬浮在内容之上。
- 桌面端约 100 × 100 px，移动端约 84 × 84 px。
- 环形文字持续旋转，显示 `FEEDBACK`。
- hover / focus 时中心箭头切换为“意见反馈”。
- 复用 Uiverse `fresh-goose-83` 的旋转文字和箭头切换思路。

### 2. Feedback 弹窗 ✅

- 点击悬浮按钮打开原生 `<dialog>`。
- 支持关闭按钮、Esc 和点击遮罩关闭。
- 遮罩带模糊效果，弹窗居中并在移动端自适应。
- 深色模式使用深蓝渐变，浅色模式使用白色玻璃与淡蓝渐变。
- 结构参考 `quiet-turkey-90`，背景参考 `brave-dog-61`，输入框参考 `curvy-earwig-22`。

### 3. 反馈表单 ✅

- 仅收集必填反馈内容。
- 1–1000 字限制，实时显示计数。
- 空内容不能提交。
- 提交中禁用按钮，防止重复点击。
- 成功后显示中英双语提示，清空内容并自动关闭。
- 失败后保留内容并显示错误信息。

### 4. Supabase 写入 ✅

- 使用原生 `fetch` 向 Supabase REST API 提交。
- 前端仅使用 anon public key。
- 数据写入 `public.feedback`。
- `created_at` 由数据库自动生成。
- 不在前端使用 `service_role` / secret key。

### 5. 数据安全与 RLS ✅

- `feedback` 表启用 RLS。
- anon 只允许 INSERT。
- anon 禁止 SELECT 已有反馈。
- 实测匿名 POST 成功、匿名 GET 被拒绝。
- 测试数据已删除。

### 6. GitHub Pages 发布结构 ✅

- 根目录新增 `docs/` 发布镜像。
- `docs/index.html` 为公开入口。
- V3 源文件继续保留带版本号命名。
- GitHub 仓库名：`spy-personal-homepage`。
- Pages 发布路径：`main /docs`。
- 公开链接：发布后填写。

## 四、如何调整

### 4.1 调整悬浮按钮

修改 `style.V3.css` 中的 `.feedback-fab`、`.feedback-fab__text` 和 `.feedback-fab__circle`。

### 4.2 调整弹窗

修改 `.feedback-dialog`、`.feedback-card`、`.feedback-input-shell` 和 `.feedback-submit`。

### 4.3 修改 Supabase

编辑 `config.V3.js`：

```js
window.SPY_SUPABASE_CONFIG = {
  url: "你的 Project URL",
  anonKey: "你的 anon public key",
  table: "feedback"
};
```

禁止填写 `service_role` / secret key。
