### 6.2 V2.1

**V2.1 交付物**：`个人主页\V2.1\index.V2.1.html`（配 `style.V2.1.css`、`script.V2.1.js`）

本版本改动集中在「第一个页面（首屏 Hero）」：

1. 首屏新增**漂浮 3D 粒子动态背景**：持续旋转 + 匀速上浮 + 近大远小的伪 3D 纵深 + 由远及近绘制
2. 粒子配色：克莱因蓝亮调 `#2f6bff`（62%）+ 浅蓝 `#8ab4ff`（24%）+ 浅蓝 `#7ea6ff`（14%）
   （初版点缀色为青色 `#35d6ff`，已按需求改为浅蓝，粒子统一在蓝色系内）
3. 首屏**「联系我」按钮改用 Shimmer Button**（Magic UI `Shimmer Button` 原生 CSS 移植）：
   边框一圈白光持续扫过 + 光带自旋 + 内阴影高光 + hover 上浮；
   文案 / 尺寸 / 跳转锚点 `#contact` 与原按钮一致；参数为 `.btn-shimmer` 上的 CSS 变量
4. 首屏粒子新增**鼠标指针交互**（本版本自有扩展，官方组件没有）：
   指针附近的粒子被**缓慢推开**，指针移开后**缓慢合拢回原位**；
   采用「目标偏移 + 指数缓动」模型（`CONFIG.interact`），公式中没有速度项，
   因此**不会回弹、不会震荡**——早先用弹簧-阻尼模型会有来回摆动，已按需求改掉
5. 首屏边缘柔化淡出，与下方区块自然过渡
6. Hero 布局由「限宽 1140px」改为「铺满视口宽 + 内部内容限宽 1140px」（否则粒子只能铺中间一条）

   移动端粒子降至 20%、DPR 上限 2
8. 新增内联 SVG favicon（克莱因蓝环形 + 浅蓝点），消除 favicon 404

**技术要点（重要，避免后续误解）**：

- 粒子效果来源为 Magic UI `Floating 3D Particles`，官方实现是 **React 外壳 + Canvas 2D**（**并非 Three.js**）
- 按钮效果来源为 Magic UI `Shimmer Button`，官方实现是 React + Tailwind 的两段 CSS 动画
  （`animate-shimmer-slide` / `animate-spin-around`）
- 本项目为纯静态页面，无法直接使用官方 CLI
  （`pnpm dlx shadcn@latest add @magicui/...`，仅适用于 React + Tailwind 工程）
- 因此按官方源码 **等价移植为原生 JS / CSS**，零依赖，算法与参数体系一致
- **鼠标推开粒子是本项目自行追加的交互**（官方 Floating 3D Particles 没有该能力），
  实现位于 `script.V2.1.js`：`CONFIG.interact` 参数 + `computeTargetOffset()` 算目标偏移 +
  `tick()` 里的指数缓动段。调整手感改 `CONFIG.interact` 即可
  （`displace` 控制推开幅度、`ease` 控制快慢、`radius` 控制影响范围、`enabled: false` 关闭）
- 可调参数：粒子在 `script.V2.1.js` 顶部的 `CONFIG`（含 `CONFIG.interact`）与 `COLORS`；
  按钮在 `style.V2.1.css` 的 `.btn-shimmer` CSS 变量（`--cut` / `--speed` / `--shimmer-color` 等）

详细功能清单见：`个人主页\V2.1\V2.1已实现功能.md`；改动对比见 `个人主页\V2.1\V2.1版本说明.md` 第 6 节。

### 6.3 V2.2

**V2.2 交付物**：`个人主页\V2.2\index.V2.2.html`（配 `style.V2.2.css`、`script.V2.2.js`）

本版本改动是「**首屏以外的页面背景**」：

1. 从「关于我」到页脚，整页背景铺一层 56px 网格，**指针停在哪一格，那一格就填充克莱因蓝高亮**

   高亮格**还带两层发光**（内层 6px 亮晕 + 外层 16px 柔光，`drop-shadow`），
   光会溢出格子边界照到周围。亮度经过两轮调整（初版 36 → 增强 98.70 → **按反馈降到 58.50**），

3. 方格数量按容器尺寸动态计算（`ceil(宽/56) × ceil(高/56)`），实测 1440×1000 下为
   **26 列 × 57 行 = 1482 格**；窗口尺寸变化自动重建
4. **首屏刻意完全不参与**：网格层自 `--hero-h`（首屏实测高度 907px）开始，
   指针在首屏内移动 0 格高亮（实测验证）
5. 新增 CSS 变量 `--hero-h`（由脚本实测首屏高度后写入 `:root`，`ResizeObserver` 跟踪更新）
6. **首屏静态网格 `.bg-grid` 由「铺满整个视口」改为「只覆盖首屏」**
   （`position: fixed; inset: 0` → `position: absolute; height: var(--hero-h)`），
   首屏观感与 V2.1 完全一致，首屏以外的背景交给新的交互网格层
7. 与首屏网格**严丝合缝**：两套网格都是 56px，内容区网格额外做了 `offsetY = 首屏高度 % 56`
   的纵向偏移补偿（实测 11px），线条在交界处完全对齐
8. 滚动后高亮校正：用最近一次指针位置重新定位（而非直接清空），
   避免滚动事件晚于鼠标事件时误清刚点亮的一格
9. 无障碍：减弱动效时取消填充过渡（高亮改为瞬时切换）；
   网格层 `aria-hidden="true"` 纯装饰，不进入无障碍树
10. **全站玻璃拟态（Glassmorphism）**（V2.2 内微调，2026-09-17）：页面上所有「半透明框」统一换成玻璃
    —— 半透明底 + **背后模糊**（`backdrop-filter`）+ 1px 浅色描边 + 上沿内高光 + 柔和外阴影。
    覆盖 **18 张内容卡片 + 顶部导航条 + 各类小控件**（首屏标签、状态胶囊、次按钮、复制按钮、
    兴趣图标块、项目占位标签、头像占位面板、进度槽）。
    采用**深色磨砂**（底色 `rgba(12,19,40,0.50)`）而非浅色玻璃，只透出背后的网格与光晕，文字对比度不受影响；
    卡片悬停时描边转蓝调、外阴影变为克莱因蓝投影。
    分两档模糊（卡片 / 导航条 18px，小控件 10px）；不支持 `backdrop-filter` 的老浏览器
    自动回退成更实的底色（`@supports not` 分支），避免退化成几乎全透明而看不清字。
    令牌集中在 `:root` 的 `--glass-*`，**改一处全站生效**
11. 玻璃改造的小心处：`.shimmer-backdrop` **保持不透明**（它负责遮住 Shimmer 按钮的扫光带）；
    `.nav-link` 与 `.skill-bar` 是**有意不加模糊**的两处例外

**技术要点（重要，避免后续误解）**：

- 效果来源为 Magic UI `Interactive Grid Pattern`，官方是 **React 组件 + 内联 SVG + Tailwind 类**
  （官方默认 `width=40, height=40, squares=[24,24]`，高亮色 `gray-300/30`，过渡 `duration-100` / `duration-1000`）
- 同样无法使用官方 CLI（`pnpm dlx shadcn@latest add @magicui/interactive-grid-pattern`），
  按官方源码**等价移植为原生 SVG + JS**
- ⚠️ **关键差异**：网格层是 `pointer-events: none`（否则会挡住卡片上的按钮点击与文字选择），
  而 `pointer-events: none` 的元素**收不到 `:hover`**，
  因此官方的「在 `rect` 上用 `:hover` + React state」方案在本页面**根本不会触发**；
  本版本改为在 `window` 上监听 `pointermove`，用 `clientX/Y` 与网格层位置反推格子索引，再切换类名
- 性能：网格层位置测量结果被缓存（指针移动时不读取布局、**不触发强制重排**），
  切换高亮时只修改两个 `<rect>` 的类名，其余 1480 格不动
- 可调参数：`script.V2.2.js` 第 6 节顶部 `CONFIG`（`cell` 方格边长、`enabled` 交互开关）；
  样式在 `style.V2.2.css` 的 `.igrid-layer` / `.igrid rect` / `.igrid rect.is-hover` 段
- **玻璃拟态**技术要点：玻璃 = 半透明底 + `backdrop-filter: blur() saturate()` + 1px 浅色描边
  + 上沿内高光（`inset 0 1px 0`）+ 柔和外阴影，**五件套缺一就会退化成「一块半透明矩形」**；
  同时保留 `-webkit-` 前缀（Safari 长期只认带前缀的写法）
- 玻璃令牌集中在 `style.V2.2.css` 的 `:root --glass-*`（两档模糊：卡片/导航条 18px、小控件 10px，
  外加 150% 饱和度、斜向高光渐变、两层阴影），**改一处即全站生效**
- 玻璃改造的三条约束：① `.shimmer-backdrop` **必须保持不透明**（它的职责是遮住 Shimmer 的扫光带）；
  ② `.nav-link`（嵌在已磨砂的导航条上）与 `.skill-bar`（内凹槽）**有意不加模糊**；
  ③ 头像占位面板背后是蓝色渐变，需用更深的半透明底（`rgba(10,19,48,0.78)`）保证「SP」文字对比度
- 兼容：加了 `@supports not ((backdrop-filter: blur(2px)) or (-webkit-backdrop-filter: blur(2px)))`
  分支，老浏览器上把玻璃面换成更实的底色，**可读性优先**

详细功能清单见：`个人主页\V2.2\V2.2已实现功能.md`；改动对比见 `个人主页\V2.2\V2.2版本说明.md` 第 6 节。

- `index.V2.html`、`style.V2.css`、`script.V2.js`
